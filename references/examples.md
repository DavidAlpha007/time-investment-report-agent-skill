# 三份样例报告的关键数据与结论

完整样例见 `assets/` 之外的工作区文件 `time-investment-reports.html`。
本文件抽取每份报告的**方法要点**，供出报告时对照。

## 报告 001 · Machine Learning Specialization（吴恩达，95 小时）

**类型**：课程 ｜ **拆分单位**：周 / 模块

| 发现 | 数据 | 置信度 |
|---|---|---|
| 总投入 | 约 95 小时（3 门课） | [官方] |
| Week 1 的 20 支视频中，前 8 支导论占比 | 29% | [推算] 官方时长加总 |
| 视频占总投入比例 | 24.5%，其余 75% 是实验与作业 | [官方 + 推算] |
| 时效折损 | **致命**：2022 年重构版不含 transformer、LLM、MLOps、部署 | [官方] 大纲核对 |
| 公认较弱的一门 | Course 3（多家第三方评测一致） | [聚合] |
| 真正不可替代的部分 | Course 2 的偏差-方差诊断 | [聚合] |

**方法要点**：

1. **课程的「视频时长」不等于「投入时长」。** 官方标注的往往是视频时长，作业与实验可能占 75%。必须用作业占比重算时间账单，否则第 1 格就错。
2. **课程类第 4 格（时效折损）权重最高。** 缺失目标技术栈可以一票否决，无需再看其他格。
3. **找「真正不可替代的那一段」，比给整门课下结论有用。** 这一条直接支撑 B 选项。

## 报告 002 · 《权力的游戏》全 8 季（70.2 小时 / 4,210 分钟）

**类型**：剧集 ｜ **拆分单位**：季 / 集

| 发现 | 数据 | 置信度 |
|---|---|---|
| 总时长 | 70.2 小时（4,210 分钟），73 集 | [推算] 逐集加总 |
| 各季加权均分 | S4 最高 9.3，S8 最低 6.4 | [聚合] 单集评分 |
| **崩点** | **S8E4**：前 3 集仍在 7.5–7.9，第 4 集骤降至 5.5，结局 4.0 | [聚合 + 推算] |
| 好评区间时长 | 66.2 小时，占 94.3% | [推算] |
| 崩塌区间时长 | 约 4 小时，占 5.7% | [推算] |

**两个反直觉结论**：

1. **94.3% 的时长处在良好区间。** 但这一条**不能**被表述为「可以放心看」——峰终效应意味着占比 5.7% 的结局支配了 70 小时的回报。叙事型内容必须单独提示尾部。
2. **全剧均分 8.8 是最没用的数字。** 它既掩盖了前 7 季的稳定高质量，也保护不了你的投入。这正是「分布优于均值」的教科书级案例。

**方法要点**：

- 单集评分 → 各季加权均分 → 崩点检测，全部用 `scripts/tir.py timeline` 完成，不心算
- 崩点必须精确**到集**，说「最后一季崩了」是不合格的

## 报告 003 ·《原则》Ray Dalio（576 页）

**类型**：书籍 ｜ **拆分单位**：篇章

| 发现 | 数据 | 置信度 |
|---|---|---|
| 成书篇幅 | 576 页 | [官方] |
| **作者本人的免费原版** | 2010 年公开的 123 页 PDF | [官方] |
| 篇幅倍数 | 成书是原版的 4.7 倍 | [推算] |
| 超出原始原则文本的篇幅占比 | 约 79% | [推算] |
| 时效折损 | **极低**（原理与方法论，不依赖时效） | [推算] |

**方法要点**：

1. **找到「作者本人的更短原版」是本方法最高价值的发现。** 它把决策从「读不读 576 页」变成「读不读 123 页」——替代源优先级里的第 1 层。
2. **超出部分不是废话，但要问对问题。** 79% 的增量含自传与落地案例。所以报告不给结论，而是问：「你是需要案例的人，还是只需要规则本身的人？」
3. **「时效折损接近零」本身是有价值的信息。** 与前两个对象形成鲜明对比，必须明确写出，不要因为「没发现问题」就省略这一格。

## 三份报告的横向对照

| | 001 课程 | 002 剧集 | 003 书籍 |
|---|---|---|---|
| 权重最高的一格 | 4 · 时效折损 | 3 · 密度异常点 | 5 · 更短替代源 |
| 关键方法 | 重算含作业的真实投入 | 单集评分 + 崩点检测 | 找作者本人的压缩版 |
| 尾部处理 | 按占比（知识型） | **单独提示**（叙事型，峰终效应） | 按占比（知识型） |
| 时效折损 | 致命 | 极低 | **极低**（需明确写出） |

**读法**：不同类型的内容，权重最高的一格不同。不要用同一份力度平均分配七格——
每份报告应当有**一格是致命的**，其余格服务于它。
